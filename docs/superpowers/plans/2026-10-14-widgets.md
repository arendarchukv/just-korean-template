# Practice widgets — Implementation Plan

> Executed inline (superpowers:executing-plans). Spec: `docs/superpowers/specs/2026-10-14-widgets-design.md`.

**Goal:** Flashcards and quiz as small Svelte islands on their own practice pages, progress in
`localStorage`, linked from Practice and lesson pages.

## Global Constraints

- One widget per page; no links or shared state between widgets; storage optional (try/catch).
- JS files only on deck/quiz pages; every other page stays without JS files.
- UI copy in `src/i18n/ui.ts`, passed to widgets as `labels`.
- Semantic tokens only; WCAG AA; touch targets ≥ 44px; keyboard operable.
- Commits without a co-author trailer.

## Review Focus

- Storage throws (private mode): widgets still work, nothing crashes.
- A deck where every card is known: the end screen hides "Practise the rest".
- A fill answer with extra spaces or different case is accepted; an alternative is accepted.
- Reloading keeps known cards and the best score; "Start over" clears known cards.
- Without JS the page still shows the cards / questions.

---

### Task 1: Widget logic (`src/lib/widgets.ts`)

Produces: `isFillCorrect(input: string, answer: string, alternatives?: string[]): boolean`,
`remainingCards<C extends { front: string }>(cards: C[], known: Set<string>): C[]`,
`readStore<T>(key: string, fallback: T): T`, `writeStore(key: string, value: unknown): void`,
`deckKey(id)` → `jk:deck:<id>`, `quizKey(id)` → `jk:quiz:<id>`.

Tests first (`src/lib/widgets.test.ts`): case/space-insensitive fill, alternatives, wrong answer;
remaining cards keep order and skip known; `readStore` returns the fallback when the stored JSON
is broken or `localStorage` throws; `writeStore` never throws.

### Task 2: Flashcards widget and deck pages

`src/components/widgets/Flashcards.svelte` (props `deckId`, `cards`, `labels`),
`src/views/DeckView.astro`, `src/pages/practice/deck/[id].astro` (+ `ko/`), i18n `deck.*`,
`src/styles/widgets.css`. No-JS fallback: a `<noscript>`-free plain list rendered by Astro inside
the island's fallback slot (the island renders over it when hydrated).

Tests first: `tests/ui/flashcards.spec.ts` — flip by click and by keyboard, "I know it" advances
and counts, end summary, "Practise the rest" shows only unknown cards, known cards survive a
reload, "Start over" clears them; `check:dist` — deck pages exist in both languages with the
fallback list.

### Task 3: Quiz widget and quiz pages

`src/components/widgets/Quiz.svelte` (props `quizId`, `questions`, `labels`), `QuizView.astro`,
`src/pages/practice/quiz/[id].astro` (+ `ko/`), i18n `quiz.*`.

Tests first: `tests/ui/quiz.spec.ts` — wrong choice shows wrong state, the correct option and the
explanation; fill accepts an alternative; final score; best score survives a reload; "Try again"
restarts; `check:dist` — quiz pages exist with the fallback list.

### Task 4: Links, checks, budget, docs

Practice list items link to deck/quiz pages (note removed); lesson page practice links point to
them; `check:dist`: links resolve, pages without widgets load no JS files; perf budget measures a
deck page with a JS limit (< 30 KB brotli); axe list gains deck and quiz pages; `docs/features.md`
(wishes 2 and 8) and `CLAUDE.md` updated.
