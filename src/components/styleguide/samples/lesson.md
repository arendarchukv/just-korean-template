The two patterns below both describe an action that **makes no difference**. They often translate to the same English sentence, but they are not interchangeable: one looks at the _result_, the other at the _choice_.

## <ruby>봤자<rt>봗짜</rt></ruby>: whatever you do, the result stays the same

Use <mark lang="ko">-아/어 봤자</mark> when the speaker is sure that trying is pointless, because the outcome is already decided. The second clause is usually negative or dismissive.

- 지금 가 봤자 아무도 없을 거예요. — Even if you go now, nobody will be there.
- 말해 봤자 소용없어요. — There is no point in telling them.
- 비싸 봤자 얼마나 비싸겠어요? — How expensive can it really be?

### How to build it

1. Take the verb stem: <span lang="ko">가다 → 가</span>.
2. Add <span lang="ko">-아/어</span> following vowel harmony: <span lang="ko">가 → 가</span>, <span lang="ko">먹 → 먹어</span>.
3. Attach <span lang="ko">봤자</span>: <span lang="ko">가 봤자</span>, <span lang="ko">먹어 봤자</span>.

> A useful way to remember it: <span lang="ko">봤자</span> comes from <span lang="ko">보다</span>, "to try". You _tried_, and it changed nothing.

## <span lang="ko">(으)나 마나</span>: doing it or not, it's the same

<span lang="ko">(으)나 마나</span> puts both options side by side — doing and not doing — and says the choice does not matter. Compare the emphasis in Korean: <em lang="ko">하나 마나</em> versus <em lang="ko">해 봤자</em>.

| Pattern                             | Looks at             | Typical second clause | Example                                      |
| ----------------------------------- | -------------------- | --------------------- | -------------------------------------------- |
| <span lang="ko">-아/어 봤자</span>  | the result of trying | negative, dismissive  | <span lang="ko">가 봤자 없어요</span>        |
| <span lang="ko">-(으)나 마나</span> | the choice itself    | "it's obvious"        | <span lang="ko">보나 마나 늦을 거예요</span> |

---

<details>
<summary>Why not use <span lang="ko">-아/어도</span> here?</summary>

<span lang="ko">-아/어도</span> ("even if") is neutral: the second clause can be positive. <span lang="ko">봤자</span> and <span lang="ko">(으)나 마나</span> always carry the speaker's judgement that the effort is useless.[^1]

</details>

Formal writing rarely uses either pattern; in speech both are very common, and <span lang="ko">보나 마나</span> often closes a sentence on its own as <span lang="ko">보나 마나지</span>.

[^1]: The same judgement appears in fixed phrases such as <span lang="ko">말하나 마나</span>.
